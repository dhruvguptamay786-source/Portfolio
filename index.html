// 01. ABOUT ME

Foundations Built Right

From binary fundamentals and C pointers to browser rendering engines.

I am a 1st-year Bachelor of Technology (B.Tech) student in Computer Science & Engineering. My engineering journey began with the belief that exceptional developers must deeply understand both the low-level machine architecture and high-level user interfaces.

In my university coursework, I spend my time breaking down algorithms in C and C++, understanding memory allocation (pointers, structs, stack vs heap), and crafting clean, accessible user interfaces using pure semantic HTML5, modern CSS, and ES6+ JavaScript.

Rather than jumping straight to heavy bloated frameworks, I chose to build this complete portfolio and embedded interactive application from scratch using pure Vanilla web technologies so I can defend every single line during my academic viva.
